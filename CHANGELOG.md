# Changelog

All notable changes to NightCode-JARVIS are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses semantic versioning.

## [Unreleased]

### Planned

- V2.4 Engineering Skills.

## [2.3.1]

### Added

- A single authoritative Python version source.
- Release documentation and a CLI `version` command.

## [2.3.0]

### Added

- Provider-agnostic `GenerationService`.
- Extensible prompt abstraction.
- Typed generation responses.
- Non-streaming Ollama `/api/generate` integration.
- Read-only `ai ask` command.

## [2.2.0]

### Added

- Local Ollama connection support.
- Model discovery and model selection.
- Provider health and availability status.

## [2.1.0]

### Added

- Dependency-inverted Multi-Provider Framework.
- Provider registration, discovery, and active-provider selection.
- Metadata-only provider placeholders.

## [2.0.0]

### Added

- Mission System and mission lifecycle coordination.
- Planning Engine and mission Exporter.
- Read-only Mission Reviewer.
- Historical mission review context.

## [1.x]

### Added

- Interactive CLI foundation.
- Repository exploration and file reading.
- Code and symbol explanation.
- Patch proposal generation and safe apply.
- Read-only Git assistant and allowlisted terminal assistant.
